# AI_Sync: Agent Handoff Log

AI 에이전트 간 작업 연속성을 보장하기 위한 핸드오프 로그입니다.
새로운 에이전트가 프로젝트에 투입될 때 이 문서를 먼저 읽고 컨텍스트를 파악합니다.

---

## 엔트리 포맷 (Template)

```markdown
## [YYYY-MM-DD] [S###] — [작업 요약 한 줄]
- Agent: [에이전트명 (예: Claude Code Opus 4.6)]
- 수행한 작업:
  - ...
- 생성/수정 파일:
  - ...
- Next Steps:
  - ...
```
