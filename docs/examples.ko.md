# 시작 예시

아이디어나 이미 진행된 내용이 있을 때 시작하는 순서를 단계별로 보여 줍니다. 두 예는 같은 연구를 다른 시점에서 시작합니다. A는 파장별 SNR을 시뮬레이션으로, B는 시제품 광학 센서의 측정 데이터로 비교합니다.

## A. 아이디어가 있는 경우

| 단계 | 사용자 입력 | 동작 | 사용자가 하는 일 |
|---|---|---|---|
| 아이디어 | "웨어러블 광학 센서의 파장 선택에 대해 생각 정리가 필요. 현재 생각은 피부 투과와 헤모글로빈 흡수를 같이 보면 810 nm 근처가 유리하다는 것. 근거와 반례를 함께 정리." | `1_Concept/13_Ideas/wavelength_choice.md`에 정리(로그에는 적지 않음) | 방향 판단 |
| 계획 | "이 아이디어를 검증할 구체적인 계획을 plan 문서로 작성. 시뮬레이션으로 파장별 SNR을 비교한 뒤, 시제품 센서 측정으로 확인하는 순서." | `1_Concept/12_Planning/P001_wavelength_optimization.md` 작성 | 단계 승인 |
| 세션 | "P001의 1단계부터 시작. S001 목표는 파장별 SNR 비교, 735/810/940 nm, Monte Carlo 시뮬레이션." | S001을 목표와 함께 생성(`Registry.md` 갱신), t01 배경에 P001 기록 | 목표 확정 |
| t01 | "t01: 3파장 sweep. 기준 조건은 P001에 적은 대로 3층 피부 모델, 광자 1e8." | phase 1 작성. 승인 후 phase 2에서 실행하고 관찰, 해석, 교훈 기록. 스크립트 `61_Sim/Scripts/S001_t01_*.m`, 데이터 `61_Sim/Data/S001/` | 가설과 예상 검토 후 승인 |

근거 논문은 `1_Concept/11_Literature/`에 둡니다. 규칙에 출처 신뢰 기준과 저널 도메인 목록이 들어 있습니다.

## B. 진행된 내용이 있는 경우

| 단계 | 사용자 입력 | 동작 | 사용자가 하는 일 |
|---|---|---|---|
| 데이터 넣기 | (직접) 측정 raw CSV를 `6_Exp/62_Empirical/Raw/`에 복사 | 없음. 원본은 읽기 전용으로 두고 git에서 제외하며, 기록은 t01부터 시작 | 원본 확인 |
| 세션 | "시제품 광학 센서로 3파장 반사광을 측정한 CSV가 있음. S001 목표는 이 데이터의 파장별 SNR 비교." | S001을 목표와 함께 생성(`Registry.md` 갱신) | 목표 확정 |
| t01 정제 | "t01: 데이터 개요와 정제. 포화 구간과 움직임 잡음 구간은 제외." | 정제 데이터를 `62_Empirical/Processed/S001/`에 저장. 스크립트 `63_Analysis/Scripts/S001_t01_*.m`, 범위와 필터는 조건 절에 기록 | 정제 기준 승인 |
| t02 분석 | "t02: 정제 데이터로 파장별 SNR 비교. 시뮬레이션과 같은 정의로." | phase 1 작성. 승인 후 phase 2에서 실행하고 figure(`64_Viz/S001/`), 데이터(`.mat`, `.csv`), 해석, 교훈 기록 | 가설과 예상 검토 후 승인 |

세션 마감과 점검은 [세션과 trial](sessions.ko.md), [점검](check.ko.md)에 있습니다.
