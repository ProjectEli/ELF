# Eli's Lab Framework (ELF): โปรโตคอล Base-Delta สำหรับ Agile R&D

มาตรฐานการบันทึกข้อมูลที่รวมฮาร์ดแวร์ - ซอฟต์แวร์ - การทดลอง (Protocol) ออกแบบมาเพื่อสนับสนุนวงจรข้อเสนอแนะที่รวดเร็ว (Agile) ในระหว่างการพัฒนาอุปกรณ์และเฟสตรวจสอบ R&D ประกันความสามารถในการติดตามข้อมูลที่สมบูรณ์พร้อมทำให้การบันทึกของนักวิจัยลดลง

## ปรัชญาหลัก

* **Single Source of Truth:** การออกแบบฮาร์ดแวร์ รหัสวิเคราะห์ และข้อมูลดิบเชื่อมต่อกันอย่างอินทรีย์ภายในโครงการเดียว
* **Base-Delta Logging:** ไม่บันทึกตัวแปรทุกตัว ประกาศ Baseline และบันทึกเฉพาะตัวแปรที่เปลี่ยนแปลง (Deltas) เพื่อป้องกันการหน่วงเวลาการวิจัย
* **Systematic Enforcement:** หลีกเลี่ยงข้อจำกัดความยาวชื่อไฟล์ (ข้อจำกัด 260 อักขระของ Windows) และประกันความสามารถในการทำซ้ำได้ผ่านโค้ด
* **AI Governance:** ประกันความต่อเนื่องของงาน AI agent ผ่านบันทึกส่งมอบ `0_Meta/AI_Sync.md` และบังคับใช้มาตรฐานการบันทึกแบบรวมสำหรับทั้ง AI และมนุษย์ผ่าน `0_Meta/LogConvention.md`

## ข้อมูลจำเพาะของไปไลน์การบันทึกข้อมูล

### 1. การตั้งชื่อไฟล์ (การตั้งชื่อเซสชั่น-ทดลอง)

* การระบุเงื่อนไขการทดลองหรือข้อมูลตัวแปรในชื่อไฟล์ **ห้ามไว้อย่างเคร่งครัด**
* **รูปแบบ:** `[SessionID]_[TrialID].[extension]` (เช่น `S001_t1.csv`, `S001_t2.bin`)

### 2. Base-Delta Logging (การบันทึกแบบไฮบริด)

* **บันทึกการทำงาน (`5_Exp/53_Analysis/Logs/S###_log.md`):**
  * ไฟล์ markdown บรรยายที่บันทึกวงจรสมมติฐาน-ทดสอบ-บทเรียนที่ทันทีในข้อความ
  * เขียนต่อทดลอง (`t1`, `t2`...) ในสไตล์สตรีมของสติสำนึก บันทึกเฉพาะ **ตัวแปรที่เปลี่ยนแปลงโดยจงใจ (Delta)** และผลลัพธ์ที่สังเกตได้
  * รูปแบบและกฎโดยละเอียด: อ้างอิง `0_Meta/LogConvention.md`

### 3. กฎของเอกสารการวางแผน

* แผนการวิจัย องค์ประกอบของภาพ กลยุทธ์การทดลอง เป็นต้น จัดการแยกต่างหากใน `1_Concept/13_Planning/`
* **รูปแบบ:** `P###_title.md` (เช่น `P001_wavelength_optimization.md`)
* เมื่ออ้างอิงการวางแผนจากบันทึก: `→ see 1_Concept/13_Planning/P###_xxx.md`

### 4. ข้อมูลจำเพาะการวิเคราะห์หลังการประมวลผล (Cell Mode Scripting)

* รหัสวิเคราะห์ต้องอยู่ใน `5_Exp/53_Analysis/Scripts/` หรือ `5_Exp/51_Sim/Scripts/` และต้องไม่ผสมภายในโฟลเดอร์ข้อมูล
* ใช้ไฟล์ `.m` บริสุทธิ์แทน `.mlx` เพื่อป้องกันการล็อคอินผู้ขาย
* รหัสได้รับการดำเนินการส่วนต่อส่วนโดยใช้ `%%` (Cell Mode) และข้อมูลเชิงลึกที่ได้มาจะสะท้อนในบันทึกการทำงาน
* ผลลัพธ์การวิเคราะห์ (รูป ไฟล์ mat) ถูกบันทึกใน `5_Exp/54_Viz/` หรือ `5_Exp/52_Empirical/Processed/S###/` ภายในโฟลเดอร์ต่อเซสชั่น

### 5. กฎการอ้างอิงแบบข้ามอ้างอิง

รูปแบบการอ้างอิงแบบข้ามอ้างอิงแบบรวมเพื่อประกันความสามารถในการติดตามระหว่างเอกสารโครงการ

| จาก → ถึง | รูปแบบ |
|-----------|--------|
| บันทึก → การวางแผน | `→ see 1_Concept/13_Planning/P###_xxx.md` |
| บันทึก → ข้อมูลการจำลอง | `→ see 5_Exp/51_Sim/Data/S###/` |
| บันทึก → สคริปต์ | `→ see 5_Exp/53_Analysis/Scripts/S###_analysis.m` |
| การวางแผน → บันทึก | `← tracked in 5_Exp/53_Analysis/Logs/S###_log.md` |

## AI Governance

เมื่อ AI agents (Claude, Gemini เป็นต้น) มีส่วนร่วมในโครงการ ใช้กฎต่อไปนี้:

1. **การได้มาซึ่งบริบท:** ก่อนเริ่มงาน อ่าน `0_Meta/AI_Sync.md` เพื่อยืนยันสถานะของงานก่อนหน้า
2. **ความเป็นไปตามมาตรฐานรวม:** ปฏิบัติตามกฎการบันทึกใน `0_Meta/LogConvention.md` ด้วยวิธีเดียวกับนักวิจัยมนุษย์
3. **การบันทึกการส่งมอบ:** เมื่อเสร็จสิ้นการดำเนินการ บันทึกการดำเนินการที่ดำเนิน ไฟล์ที่สร้าง/แก้ไข และขั้นตอนต่อไปใน `0_Meta/AI_Sync.md` เขียนในลำดับย้อนเวลาพร้อมรายการล่าสุดที่ด้านบน
4. **การแยกแนวคิด:** สมมติฐานและแนวคิดที่สร้างโดย AI เก็บแยกต่างหากใน `1_Concept/11_Ideas/` ไม่ใช่ในบันทึก
5. **การจัดการบริบทตาม PARA:** ใช้โฟลเดอร์ `9_Archive/` และ `.claudeignore` เพื่อป้องกันการปนเปื้อนบริบท AI สำหรับกฎโดยละเอียด โปรดอ้างอิง `0_Meta/AI_PARA_Framework.md`
6. **กฎการสื่อสาร:** รักษากรรมวิธีการเขียนที่เป็นกลางและแห้ง ไม่มีการเปรียบเทียบหรือเปรียบเทียบ ส่งมอบข้อสรุปอย่างชัดเจนและตรงไปตรงมา ไม่มีการเพิ่มเติมหรือตัวแก้ไขทางอารมณ์ สำหรับกฎโดยละเอียด โปรดอ้างอิงส่วนที่ 3 ของ `0_Meta/EliRule.md`
7. **การนำข้อมูลไปใช้ซ้ำ:** เมื่อสร้าง Plot/Graph ใด ๆ บันทึก Data Array ดั้งเดิมควบคู่ไปเป็น `.mat`/`.csv` สำหรับกฎโดยละเอียด โปรดอ้างอิงส่วนที่ 2.6 ของ `0_Meta/EliRule.md`

## เริ่มต้นอย่างรวดเร็ว

หากต้องการสร้างโครงการใหม่ที่มีโครงสร้าง ELF v2 ให้รัน `0_Meta/ELF_generator.sh`

```bash
cd desired_parent_directory
bash /path/to/ELF/0_Meta/ELF_generator.sh
```

> บน Windows ให้ใช้ Git Bash (รวมอยู่ใน [Git for Windows](https://git-scm.com/))

ป้อนชื่อโครงการและโครงสร้างโฟลเดอร์ 0–6 เอกสารเมตา และ `.gitignore` จะถูกสร้างโดยอัตโนมัติ การเริ่มต้น Git เป็นทางเลือกและจะถูกถามเฉพาะเมื่อ Git พร้อมใช้งาน
